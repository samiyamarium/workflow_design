Core Concepts & Frameworks

1. Unit of Value = Step

Habit vs. Team Workflow: Personal habits exist in heads and vary by mood. Team workflows are repeatable processes with fixed step owners.

2. Task Definition & RFP Extraction

Turns vague operational requests into 5 settled answers: What, For Whom, How Often, Data Source, and Format.

3. Computed vs. Written

If a figure matters, compute it via Code Execution. Never write it in prose because a generated estimate looks identical to a calculated truth.

4. The Window Test

Determines step eligibility: Can everything this step needs be supplied inside the model's context window? Unsupplied context stays human.

5. The Three Delegation Criteria

Reversibility, Stakes, and Accountability dictate step ownership. Past LLM performance is never a delegation criterion.

6. Three Mapping Errors

Over-delegation (Halo delegation), Unstaffed Gates (silent decay), and Mapping the Tool instead of the Work.

7. Diagnostic Sequence

Cheapest-first troubleshooting: Under-specification → Context Overload → Wrong Feature/Model → Stale Config → Expectation Mismatch.

8. Three Configuration Homes

Promote permanent fixes to their exact homes: Rules → Standing Instructions, References → Knowledge Base, Procedures → Skills.

9. Incident Response & Stakeholders

Stop, Scope, Tell, Change Map. Always explain workflows by stating: What tool does → Human Gate → What it Refuses.

Extracted System Tables & Reference Guides

Table 1: Three Layers of Workflow Implementation

Workflow Need Implementation Home Technical Rationale
Repeatable step-by-step procedure Skill Runs identically across accounts and projects without manual reprompting.
Static reference files & documentation Knowledge Base Provides persistent background context to all runs in a Project.
Calculations, data metrics, growth trends Code Execution Ensures numbers are deterministically computed rather than heuristically generated.
Global constraints & rules Standing Instruction Applies continuously without relying on user memory during prompt creation.
High-stakes or irreversible decisions Named Review Gate Ensures clear human accountability before external action is taken.

Table 3: Diagnostic Cause Matrix

Symptom Timing Primary Cause 1-Minute Confirmation Check Remediation
Wrong from 1st response Under-specification Re-read prompt against 5 required slots. Is info missing? Add missing slot details.
Degrades over long chat Context Overload Restate instruction in a fresh session. Does it hold? Restart or summarize session.
Repeatable error type Wrong Feature / Tier Run step via Code Execution or higher capability tier. Switch feature or upgrade tier.
"Used to work, now off" Stale Configuration Check last update date of Knowledge Base or Skill files. Audit & refresh configuration.
